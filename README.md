# EchoGPT — AI Assistant Chrome Extension

EchoGPT is a modern AI-powered Chrome Extension interface designed to provide a clean, fast, and intuitive AI experience directly from the browser.

The project focuses on improving the overall extension experience through a structured sidebar, better prompt interaction, AI model selection, conversation history, quick actions, and a consistent modern UI.

# 📌 Project Overview

EchoGPT is a redesigned concept for an AI Chrome Extension.

The goal of this project is to create a simple and visually consistent interface where users can quickly interact with an AI assistant without leaving their current browser workflow.

The interface includes:

* Popup UI
* Sidebar navigation
* Prompt input experience
* AI model selection
* Conversation history
* Quick actions
* Settings
* Responsive layout
* Dark/light visual support
* Modern AI-focused design system

The project uses mock/static data because backend integration is not required for the assessment.

# ✨ Key Features

## 1. Popup UI

The popup interface provides a compact AI assistant experience with:

* EchoGPT branding
* Welcome section
* AI prompt area
* Quick action cards
* Model selector
* Attachment/action buttons
* Send button
* Responsive layout

## 2. Sidebar Navigation

The sidebar provides easy access to the main EchoGPT features.

Navigation includes:

* Home
* New Chat
* AI Tasks
* Job Analysis
* AI Tools
* Image Studio
* Video Studio
* Compare
* Connectors
* Conversation History
* Store
* Support
* Subscription
* API Platform
* Settings

The navigation is designed to remain simple and easy to scan.

## 3. Prompt Input Experience

The prompt area is designed as the primary interaction point.

Users can:

* Enter an AI prompt
* Select an AI model
* Attach files
* Use additional actions
* Send prompts
* Start a new conversation

## 4. AI Model Selection

The interface includes an AI model selector so users can choose the model they want to use for their conversation.

The model selector is currently UI-based and uses mock data.

## 5. Conversation History

Users can access previous conversations through the history section.

The interface is designed to support:

* Recent conversations
* Conversation titles
* Search/navigation
* Quick access to previous chats

## 6. Quick Actions

EchoGPT includes quick actions to help users start common tasks faster.

Examples include:

* Write content
* Analyze a job
* Create a resume
* Generate social content
* Solve a challenge
* Creative assistance

## 7. Settings

A dedicated settings area provides a structured place for future configuration options.

Possible settings include:

* Appearance
* AI preferences
* Notifications
* Account settings
* Privacy
* Keyboard shortcuts

## 8. Responsive Design

The interface is designed to work across:

* Desktop
* Tablet
* Mobile-sized layouts

The navigation and content areas adapt according to screen size.

# ⚙️ Setup Instructions

## 1. Clone the Repository

```bash
git clone https://github.com/your-username/echogpt.git
```

## 2. Go to the Project Directory

```bash
cd echogpt
```

## 3. Install Dependencies

```bash
npm install
```

## 4. Start the Development Server

```bash
npm run dev
```

The application will be available at:

```text
http://localhost:3000
```

## 5. Create a Production Build

```bash
npm run build
```

## 6. Run the Production Server

```bash
npm start
```

# 🧩 Assumptions

The following assumptions were made during development:

1. Backend integration is not required for this assessment.
2. Mock/static data is used for AI responses and conversation history.
3. AI model selection is currently a frontend interaction.
4. Authentication is not implemented.
5. API integrations are represented through UI states or mock data.
6. The project is designed as a frontend prototype of a Chrome Extension experience.
7. The interface is structured so real APIs can be integrated later.
8. Responsive behavior is prioritized for different screen sizes.
